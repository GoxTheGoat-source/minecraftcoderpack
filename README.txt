  🇫🇷 VERSION FRANÇAISE
 ------------------------------------------------------------------------

 Bienvenue dans ce dépôt d'archivage du Mod Coder Pack (MCP).

 Pour organiser proprement les versions, les fichiers de chaque version
 de MCP sont stockés sur des branches distinctes de ce dépôt.

 >> COMMENT ACCÉDER AUX FICHIERS SUR GITHUB :
 1. Cliquez sur le menu déroulant des branches (qui affiche actuellement
    "main" ou "master") situé en haut à gauche de la liste des fichiers.
 2. Sélectionnez la branche de la version recherchée (ex: "1.12.2", "1.8.9").

 >> COMMENT CLONER UNE BRANCHE SPÉCIFIQUE (GIT) :
 Pour cloner directement une version spécifique :
 git clone -b <nom_de_la_branche> https://github.com/VOTRE_PSEUDO/NOM_DEPOT.git

 Exemple :
 git clone -b 1.12.2 https://github.com/VOTRE_PSEUDO/NOM_DEPOT.git


 ------------------------------------------------------------------------
  🇬🇧 ENGLISH VERSION
 ------------------------------------------------------------------------

 Welcome to this Mod Coder Pack (MCP) archive repository.

 To keep things clean and organized, the files for each MCP/Minecraft
 version are stored on separate branches of this repository.

 >> HOW TO ACCESS THE FILES ON GITHUB:
 1. Click on the branch dropdown menu (currently showing "main" or "master")
    located at the top-left of the file list.
 2. Select the branch for the version you need (e.g., "1.12.2", "1.8.9").

 >> HOW TO CLONE A SPECIFIC BRANCH (GIT):
 To clone a specific version directly:
 git clone -b <branch_name> https://github.com/YOUR_USERNAME/YOUR_REPO.git

 Example:
 git clone -b 1.12.2 https://github.com/YOUR_USERNAME/YOUR_REPO.git
